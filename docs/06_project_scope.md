# 06. 프로젝트 범위와 제한사항

## 포함 범위

- 분석 종목 등록과 관리
- 거래 기록과 Position 계산
- 공식 출처·공시·중요 정보·참고자료 관리
- 검토 대기 후보와 사용자 승인 흐름
- 통합 사건과 종목 연결
- 경제·기업 일정
- 변경 기반 브리핑
- 위험 기준과 규칙 기반 관리 방향
- 출처·검증 상태와 시스템 상태
- 로컬 Scheduler·로그·DB 안전 구조
- Backend·Frontend·Browser 자동 회귀

## 의도적으로 제외한 범위

- 자동 주문
- 증권사 계좌 인증·연동
- 계좌 잔고 자동 동기화
- 실시간 전문 주식 차트
- 투자 수익 보장
- 자동 매수·매도 성공 확률
- 사용자의 확인 없이 생성되는 투자 명령
- 기사·유료 문서 전문 저장
- 공개 인터넷 서비스용 인증·HTTPS
- 카카오톡·모바일 Push

이 항목들은 누락 기능이 아니라 프로젝트 목적 밖이거나 별도 제품 단계가 필요한 기능입니다.

## 운영 환경에서 추가 확인할 항목

- 외부 Provider live smoke
- 실제 Windows Scheduler 연속 실행
- 실제 휴대전화 same-Wi-Fi LAN
- 이메일 Provider 연결
- 시장 일정 Provider 연결
- 실제 배포 환경의 인증·HTTPS
- 장기 데이터 보관·backup 정책

## 공개 포트폴리오 제한

- 실제 투자 DB 미포함
- 개인 보유 수량·평단·계정정보 미포함
- Secret 미포함
- 로컬 절대경로를 공개 문서에 사용하지 않음
- 대표 공개 자산과 별도 시연 DB 사용
