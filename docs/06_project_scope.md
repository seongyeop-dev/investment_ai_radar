# 06. Project Scope

## 프로젝트 범위

이 프로젝트는 **투자 정보를 수집·검토·연결하고 사용자의 관리 기준을 정리하는 도구**까지를 구현 범위로 정의했습니다.

실제 주문 실행과 증권계좌 자동 연동은 제품 목적에서 제외했습니다.

## 포함 범위

- 분석 종목 등록과 관리
- 거래 기록과 Position 계산
- 공식 출처·공시·중요 정보·참고자료 관리
- 검토 대기 후보와 사용자 승인 흐름
- 통합 사건과 종목 연결
- 경제·기업 일정
- 변경 기반 브리핑
- 위험 기준과 규칙 기반 관리 방향
- 출처·검증 상태와 시스템 상태
- 로컬 Scheduler·로그·DB 안전 구조
- Backend·Frontend·Browser 자동 회귀

## 의도적으로 제외한 범위

- 자동 주문·자동매매
- 증권사 계좌 인증·연동
- 계좌 잔고 자동 동기화
- 실시간 전문 주식 차트
- 투자 수익 보장
- 자동 매수·매도 성공 확률
- 사용자의 확인 없이 생성되는 투자 명령
- 기사·유료 문서 전문 저장
- 공개 인터넷 서비스용 인증·HTTPS
- 카카오톡·모바일 Push

이 항목들은 누락 기능이 아니라 프로젝트 목적 밖이거나 별도 제품 단계가 필요한 기능입니다.

## 공개 범위

- 실제 투자 DB 미포함
- 개인 보유 수량·평단·계정정보 미포함
- Secret 미포함
- 로컬 절대경로가 포함된 내부 운영 자료 미포함
- 공개적으로 식별 가능한 대표 자산과 별도 시연 DB 사용
- 포트폴리오용 이미지·영상과 공개 가능한 소스·테스트·문서만 포함

## 운영 환경에서 추가 확인할 항목

- 외부 Provider live smoke
- 실제 Windows Scheduler 연속 실행
- 실제 휴대전화 same-Wi-Fi LAN
- 이메일 Provider 연결
- 시장 일정 Provider 연결
- 실제 배포 환경의 인증·HTTPS
- 장기 데이터 보관·backup 정책

## 최종 구현 범위

정보 수집·검토·사건 연결·일정·브리핑·관리 방향과 공개 가능한 운영 구조까지 구현했습니다.

외부 서비스나 실제 투자 DB에 의존하는 검증은 완료 항목과 분리해 문서화했습니다.
