# INVESTMENT_AI_RADAR 공개 기능 완료 요약

## 프로젝트 목적

`INVESTMENT_AI_RADAR`는 자동 주문이나 증권계좌 연동을 수행하는 앱이 아닙니다.

- 보유·관심 종목의 공시, 뉴스, 이벤트, 공식 출처와 공개 참고자료를 수집·검토합니다.
- 자동으로 발견한 자료는 후보 상태로 격리하고 사용자가 확인한 뒤 승인하거나 제외합니다.
- 공개 포트폴리오와 시연은 실제 투자 DB와 분리합니다.
- 최종 투자 판단과 실제 주문은 사용자가 별도 금융 앱에서 수행합니다.

## 최종 구현 영역

- 포트폴리오와 거래 기록
- 공식 출처·구독·변경 이력
- 애널리스트·전문가 공개 참고자료
- 검토 대기 후보와 승격·제외
- 중요 정보 웹 등록
- 공식 공시 웹 등록
- 통합 사건
- 경제·기업 일정
- 변경 기반 브리핑
- 위험 기준과 규칙 기반 종목 관리 방향
- 개인 설정
- 출처·검증 상태와 시스템 연결 상태
- 별도 공개 시연·recording session DB 구조

## 완료 상태


기능 구현과 포트폴리오 촬영을 완료했고, 2026-08-07 전체 최종 QA를 다시 실행해 공개 QA 문서에 반영했습니다.

## 범위 제외

- 자동 주문·자동매매
- 증권계좌 연동
- 투자 판단 자동화와 수익 보장
- 실시간 전문 차트
- 인증·HTTPS를 갖춘 외부 공개 서비스
- 카카오톡·모바일 Push
