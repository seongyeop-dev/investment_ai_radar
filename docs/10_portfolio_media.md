# 10. Portfolio Media

## 미디어 역할

이 문서는 이미지와 영상의 **전체 인덱스**입니다.

미디어를 이 문서에만 따로 모아 두지 않고, 실제 기능 설명이 있는 [03. Features](03_features.md)에 해당 이미지·영상을 함께 배치했습니다. 13개 영상의 검증 결과는 [05. Validation](05_validation.md)에 별도로 기록합니다.
