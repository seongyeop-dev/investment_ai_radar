# 10. Portfolio Media

## 미디어 구성

포트폴리오에는 대표 스크린샷 15장과 기능 시연 편집 영상 13개를 정리했습니다.

실제 투자 DB와 개인 계정 정보는 사용하지 않고 공개적으로 식별 가능한 대표 자산과 별도 recording session DB를 사용했습니다.

## 시연 데이터

대표 공개 자산:

- Samsung Electronics (`005930`, KRX)
- Microsoft (`MSFT`, NASDAQ)
- Bitcoin (`BTC`, UPBIT)

공개적으로 식별 가능한 자산을 사용하지만 개인 보유 수량·평단·계정 정보는 사용하지 않습니다.

## 활용 기준

- README에는 전체 흐름을 보여주는 대표 화면만 배치합니다.
- 기능별 전체 이미지·영상은 이 문서에서 인덱스로 관리합니다.
- 촬영 환경과 시연 순서는 [Demo Guide](demo/README.md)에서 설명합니다.
- 실제 투자 데이터와 Secret이 노출된 원본은 포트폴리오 미디어에 포함하지 않습니다.
