# 03. Features

## 기능 구성

Investment AI Radar는 **종목 관리 → 정보 수집·등록 → 검토 → 사건 연결 → 일정·브리핑 → 사용자 판단** 흐름을 중심으로 구성했습니다.

각 기능 아래에 해당 화면과 시연 영상을 직접 연결해, 구현 내용과 증빙을 같은 위치에서 확인할 수 있도록 구성합니다.
