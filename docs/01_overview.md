# 01. 프로젝트 개요

## 문제 정의

개인 투자자는 보유·관심 종목을 관리하면서 공시, 뉴스, 기관 자료, 전문가 공개 자료와 경제 일정을 여러 사이트에서 반복 확인하게 됩니다.

이 과정에서 다음 문제가 생깁니다.

- 중요한 자료 누락
- 같은 자료의 반복 확인
- 공식 출처와 2차 출처의 혼재
- 검토 여부와 판단 근거의 단절
- 거래 기록과 정보 이벤트의 분리
- 변경된 사실만 빠르게 확인하기 어려움

## 해결 방향

Investment AI Radar는 자동매매 시스템이 아니라 **투자 정보 수집·검토·관리 지원 시스템**입니다.

```text
정보 등록·수집
→ 출처와 중복 확인
→ 검토 대기 또는 정식 자료로 관리
→ 종목·통합 사건과 연결
→ 관리 방향·다음 확인 일정 정리
→ 변경 기반 브리핑
```

## 설계 원칙

1. 사용자 포트폴리오를 정보 연결의 중심으로 둡니다.
2. 공식 출처, 2차 출처와 참고자료를 구분합니다.
3. 자동 발견 자료는 즉시 판단 근거로 사용하지 않고 검토 상태로 격리합니다.
4. 없는 데이터는 추정하지 않고 `미설정`, `비활성`, `데이터 부족`으로 표시합니다.
5. 관리 방향은 규칙 기반 검토 결과이며 매수·매도 명령이 아닙니다.
6. 실제 거래와 최종 투자 판단은 사용자가 외부 금융 앱에서 수행합니다.
7. 공개 시연과 실제 투자 데이터 저장소를 분리합니다.

## 구현 결과

- 분석 종목과 거래 원장
- 중요 정보, 공식 공시와 통합 사건
- 공식 출처·구독·변경 이력
- 애널리스트·전문가 참고자료
- 검토 대기 후보 흐름
- 경제·기업 일정과 다음 확인 일정
- 변경 기반 브리핑
- 위험 기준과 종목 관리 방향
- 출처·검증 상태 및 시스템 상태
- 별도 시연 DB와 공개 미디어

## 현재 단계

기능 구현과 포트폴리오 촬영을 완료했으며, 최종 전체 QA와 공개 Git 저장소 정리 단계입니다.
