# 01. Overview

## 개발 배경

개인 투자자는 보유·관심 종목을 관리하면서 공시, 뉴스, 기관 자료, 전문가 공개 자료와 경제·기업 일정을 여러 사이트에서 반복 확인하게 됩니다.

이 과정에서 자료 누락, 중복 확인, 공식 출처와 2차 출처의 혼재, 거래 기록과 정보 이벤트의 분리, 변경된 사실을 빠르게 파악하기 어려운 문제가 발생할 수 있습니다.

## 문제 정의

- 중요한 자료 누락
- 같은 자료의 반복 확인
- 공식 출처와 2차 출처의 혼재
- 검토 여부와 판단 근거의 단절
- 거래 기록과 정보 이벤트의 분리
- 변경된 사실만 빠르게 확인하기 어려움

## 프로젝트 목적

Investment AI Radar는 자동매매 시스템이 아니라 **투자 정보 수집·검토·관리 지원 시스템**입니다.

종목별로 흩어진 정보를 출처와 근거를 기준으로 정리하고, 사건·일정·브리핑과 연결해 사용자가 다음 확인 항목과 관리 방향을 판단할 수 있도록 구성했습니다.

## 해결 방향

```text
정보 등록·수집
→ 출처와 중복 확인
→ 검토 상태 관리
→ 종목·통합 사건 연결
→ 일정·변경 항목 정리
→ 변경 기반 브리핑
→ 사용자 최종 판단
```

## 설계 원칙

1. Portfolio를 정보 연결의 중심으로 둡니다.
2. 공식 출처, 2차 출처와 참고자료를 구분합니다.
3. 자동 발견 자료는 검토 전 판단 근거로 사용하지 않습니다.
4. 없는 데이터는 추정하지 않고 `미설정`, `비활성`, `데이터 부족`으로 표시합니다.
5. 관리 방향은 규칙 기반 검토 결과이며 주문 명령이 아닙니다.
6. 최종 투자 판단과 실제 주문은 사용자가 외부 금융 앱에서 수행합니다.
7. 실제 투자 데이터와 테스트·검증 데이터를 분리합니다.

## 최종 구현 범위

- 분석 종목과 거래 기록
- 공식 출처·구독·변경 이력
- 애널리스트·전문가 공개 참고자료
- 검토 대기 후보 흐름
- 중요 정보·공식 공시·통합 사건
- 경제·기업 일정과 다음 확인 일정
- 변경 기반 브리핑
- 위험 기준과 종목 관리 방향
- 출처·검증 상태와 시스템 연결 상태
- 자동 회귀와 실제 UI 기능 검증

## 최종 결과

정보 수집부터 사용자 판단 전 단계까지의 흐름을 하나의 웹 애플리케이션으로 통합했고, 자동화 QA와 실제 UI 기능 시나리오를 통해 최종 동작을 검증했습니다.

자동 주문·계좌 연동 없이 **정보의 출처·검토 상태·사건 연결·변경 여부를 관리하는 의사결정 보조 도구**라는 프로젝트 범위를 유지했습니다.
